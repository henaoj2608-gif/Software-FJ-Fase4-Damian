 Software FJ - Gestión Integral

## Descripción del proyecto

Software FJ es un sistema desarrollado en Python para la gestión de clientes, servicios y reservas de una empresa.

El proyecto permite administrar la información de los clientes, consultar los servicios disponibles y gestionar las reservas mediante una interfaz gráfica.

## Funcionalidades principales

- Registro y consulta de clientes.
- Validación de correos electrónicos y teléfonos.
- Catálogo de servicios disponibles.
- Creación de reservas.
- Confirmación y cancelación de reservas.
- Cálculo automático de costos y descuentos.
- Actualización de datos de clientes.
- Registro de eventos y errores del sistema.
- Interfaz gráfica desarrollada con Tkinter.
- Pruebas unitarias para verificar el funcionamiento.

## Tecnologías utilizadas

- Python.
- Visual Studio Code.
- Tkinter.
- Git y GitHub.
- Programación orientada a objetos.
